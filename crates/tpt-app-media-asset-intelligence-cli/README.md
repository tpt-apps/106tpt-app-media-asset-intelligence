# tpt-app-media-asset-intelligence-cli

Batch interface for TPT Media Asset Intelligence: index, search, dedupe and tag commands sharing the GUI's engine, with a stable exit-code contract (spec §14).

Part of **TPT Media Asset Intelligence** — a local-first media archive indexing, search, dedupe and archive-health platform (TPT Solutions). See the workspace [README](../../README.md) and [spec.txt](../../spec.txt) for the product definition.
