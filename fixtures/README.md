# Golden fixture archives (spec §19.2)

Synthetic archives with **known expected results**. Each fixture directory documents its expected index counts, duplicate groups, and scene boundaries in its `README.md`; Phase 1's golden tests (§26 step 20) assert against those documents.

| Fixture | Purpose |
| :--- | :--- |
| `synthetic-archive-small/` | small archive, fully documented expectations |
| `synthetic-archive-large/` | scale/performance regression source (§19.3) |
| `duplicates/` | exact-hash, perceptual and audio-fingerprint duplicate groups |
| `corrupt/` | malformed media that must not crash indexing (§17) |
| `mixed-formats/` | container/codec breadth across the supported matrix |

Synthetic media is generated by build-time helpers (reusing `tpt-av-asset-test-media` where possible, spec §5.2) rather than committed as large binaries; expected results are hand-maintained per fixture.
